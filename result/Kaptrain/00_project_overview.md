# Project Overview: Kaptrain

## 📝 Description
Kaptrain is a comprehensive coaching and fitness management platform designed for professional coaches and athletes. It provides tools for training program creation, performance tracking, and athlete wellness monitoring. The system consists of a Web CMS for Coaches/Admins and a Mobile Application for Athletes.

## 👥 Personas
1. **Super Admin**: Manages platform-wide settings, subscription plans, and has full coach/athlete oversight.
2. **Coach**: Creates individual and program-based training sessions, monitors athlete wellness, and manages their own roster of athletes.
3. **Athlete**: Performs training sessions, logs performance records, tracks daily wellness metrics, and communicates with their coach.

## 🛠️ Tech Stack
- **Frontend (Web CMS)**: Likely React/Next.js (Vercel mentioned).
- **Mobile App**: Likely Flutter or React Native (Apple/Google Play Store mentioned).
- **Backend / Database**: Supabase (PostgreSQL).
- **Infrastructure**: GCP, IONOS (DNS), Brevo (Email), Stripe (Payments).
- **Languages**: French (Primary), English.

## 🎯 Key Domain Values
- **High-Fidelity Coaching**: Training blocks and cycles allow for precision planning.
- **Holistic Wellness**: Integration of mood, sleep, and physical soreness into training adjustments.
- **Hybrid Monetization**: Support for both one-time purchases and ongoing subscriptions.
