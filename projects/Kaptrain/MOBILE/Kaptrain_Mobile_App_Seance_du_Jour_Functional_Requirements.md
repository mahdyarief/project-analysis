## APP – FR-XXX Séance du jour (Bibliothèque)

**Description**  
Display the “Séance du jour” workout generated by Kaptrain, allowing athletes to view, execute, and complete the daily training session.

**Actor**  
Athlete (primary)

**Priority**  
High

**Acceptance Criteria**
- User can access “Séance du jour” from the **Bibliothèque** menu.
- Screen displays:
  - Title of the session (e.g., *HIIT 20×20 – Puissance & Résistance*).
  - Estimated session duration.
  - List of training blocks (e.g., warm‑up, main block), each expandable/collapsible.
  - Exercise descriptions inside each block, including repetitions, duration, or movement details.
- User can expand/collapse each block to read instructions.
- User can mark a block as completed by checking its checkbox.
- A timer icon is displayed if the block contains time‑based exercises.
- User can scroll to view the full structured program.
- “J’ai terminé” button is available at the bottom of the session.
- When clicking **J’ai terminé**, system redirects user to the **Fin de séance** flow.
- If the session has already been completed, system displays it as completed and prevents duplication.
