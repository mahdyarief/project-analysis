## CMS – FR-XXX Access Exercise Library

**Description**  
Allow Coaches to access the Exercise Library from the main navigation to browse all available exercises.

**Actor**  
Coach

**Priority**  
High

**Acceptance Criteria**

- Coach can access the Library from the sidebar navigation.
- The Library displays a list of all available exercises.
- Exercises are loaded with basic metadata (name, thumbnail, tags).
- The system supports two display layouts: list view and grid view.

## CMS – FR-XXX Switch Library Layout

**Description**  
Allow Coaches to switch between list and grid layouts in the Exercise Library.

**Actor**  
Coach

**Priority**  
Medium

**Acceptance Criteria**

- Coach can toggle between list and grid layouts.
- The selected layout persists during the session.
- Both layouts display consistent exercise information.

## CMS – FR-XXX Search Exercises

**Description**  
Allow Coaches to search for exercises using keywords.

**Actor**  
Coach

**Priority**  
High

**Acceptance Criteria**

- Coach can search exercises by name.
- Results update dynamically as keywords are entered.
- Empty states are shown when no results match.

## CMS – FR-XXX Filter Exercises

**Description**  
Allow Coaches to filter exercises by sport, muscle group, or thematic category.

**Actor**  
Coach

**Priority**  
High

**Acceptance Criteria**

- Coach can apply one or multiple filters.
- Filters can be cleared individually or all at once.
- The exercise list updates based on active filters.
