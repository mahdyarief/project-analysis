# Kaptrain – CMS Dashboard Functional Requirements

## CMS – FR-029 Dashboard Overview
**Description**  
Allow CMS users (Admin and Coach) to access a dashboard providing an overview of key metrics, athletes status, messaging, and notifications.

**Actor**  
Admin, Coach

**Priority**  
High

**Acceptance Criteria**
- Admin and Coach can access the dashboard after successful login.
- Dashboard displays subscription or plan information relevant to the user.
- Dashboard displays revenue or usage metrics when applicable to the user role.
- Displayed metrics reflect the latest available data.

---

## CMS – FR-030 Athlete Overview
**Description**  
Allow CMS users to view an overview of athletes associated with them.

**Actor**  
Admin, Coach

**Priority**  
High

**Acceptance Criteria**
- The system displays a list of athletes linked to the logged-in user.
- Each athlete shows a current status or condition indicator.
- Admin and Coach can view basic athlete information.
- Admin and Coach can navigate to the full athletes list.

---

## CMS – FR-031 Messaging Summary
**Description**  
Allow CMS users to view a summary of recent messages.

**Actor**  
Admin, Coach

**Priority**  
Medium

**Acceptance Criteria**
- The system displays recent conversations.
- Each message preview includes sender and timestamp.
- Users can navigate to the messaging module from the dashboard.

---

## CMS – FR-032 Notifications Summary
**Description**  
Allow CMS users to view recent notifications related to athletes and system events.

**Actor**  
Admin, Coach

**Priority**  
Medium

**Acceptance Criteria**
- The system displays a list of recent notifications.
- Notifications include type and timestamp.
- Users can navigate to the full notifications list.

---

## CMS – FR-033 AI Insights (Future Feature)
**Description**  
Provide an AI-powered assistant to analyze athlete data and answer user questions.

**Actor**  
Admin, Coach

**Priority**  
Low

**Acceptance Criteria**
- The AI Insights feature is visible but marked as unavailable.
- No functional behavior is required until the feature is enabled.
