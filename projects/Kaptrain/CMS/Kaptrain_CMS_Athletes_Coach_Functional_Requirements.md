# Kaptrain – CMS Athletes (Coach) Functional Requirements

## CMS – FR-038 Athletes List (Consult My Athletes)
**Description**  
Allow Coaches to view and manage the list of athletes associated with their account.

**Actor**  
Coach

**Priority**  
High

**Acceptance Criteria**
- Coach can access the athletes list.
- The system displays all athletes linked to the Coach.
- Each athlete shows basic profile information and current form status.
- Coach can search athletes by name.
- Coach can view upcoming training information per athlete.
- Coach can see associated sports for each athlete.
- Athlete list reflects the latest available data.

---

## CMS – FR-039 Athlete Invitation & Confirmation
**Description**  
Allow Coaches to manage athlete invitations and confirmations.

**Actor**  
Coach

**Priority**  
High

**Acceptance Criteria**
- Coach can view pending athlete confirmations.
- Coach can accept an athlete invitation.
- Coach can refuse an athlete invitation.
- Accepted athletes are added to the active athlete list.
- Refused invitations are removed from pending confirmations.

---

## CMS – FR-040 Athlete Notifications Panel
**Description**  
Allow Coaches to view and filter athlete-related notifications.

**Actor**  
Coach

**Priority**  
Medium

**Acceptance Criteria**
- Coach can view athlete-related notifications.
- Notifications are grouped by type (urgent, important, neutral).
- Coach can filter notifications by type.
- Coach can reset applied filters.
- Notifications reflect real-time or latest available data.

---

## CMS – FR-041 Athlete Overview (Detail Panel)
**Description**  
Allow Coaches to view a detailed overview of a selected athlete.

**Actor**  
Coach

**Priority**  
High

**Acceptance Criteria**
- Coach can select an athlete from the list.
- The system displays athlete overview data.
- Overview includes health, wellness, and performance indicators.
- Coach can view upcoming training sessions.
- Coach can view reported injuries and their status.

---

## CMS – FR-042 Athlete Messaging
**Description**  
Allow Coaches to communicate directly with athletes.

**Actor**  
Coach

**Priority**  
High

**Acceptance Criteria**
- Coach can access the messaging view for a selected athlete.
- Coach can view the conversation history.
- Coach can send messages to the athlete.
- Sent messages appear immediately in the conversation.
- Messaging reflects the latest available data.
