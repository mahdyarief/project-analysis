# Kaptrain CMS – Library Filters Functional Requirements

## CMS – FR-XXX Access Library Filters

**Description**  
Allow Coaches to open the filter panel from the Exercise Library to refine the list of exercises.

**Actor**  
Coach

**Priority**  
High

**Acceptance Criteria**

- Coach can open the Filters panel from the Library page.
- Filters panel opens as a side sheet without leaving the Library.
- Coach can reset all filters using a “Clear all” action.
- Applied filters persist until cleared or changed.

## CMS – FR-XXX Filter Exercises by Sports

**Description**  
Allow Coaches to filter exercises by one or multiple sports.

**Actor**  
Coach

**Priority**  
High

**Acceptance Criteria**

- Coach can open the Sports filter from the Filters panel.
- Coach can search for a sport by name.
- Coach can select one or multiple sports.
- Selected sports are displayed as active filter tags.
- Exercise list updates after applying the filter.
- Coach can clear selected sports.

## CMS – FR-XXX Filter Exercises by Thematic

**Description**  
Allow Coaches to filter exercises based on training thematics and targeted zones.

**Actor**  
Coach

**Priority**  
Medium

**Acceptance Criteria**

- Coach can select one or multiple thematics (e.g. Mobility, Warm-up).
- Coach can optionally select body zones (e.g. Lower body, Core).
- Selected thematics and zones refine the exercise list.
- Filters can be cleared independently or all at once.

## CMS – FR-XXX Filter Exercises by Materials

**Description**  
Allow Coaches to filter exercises based on required equipment.

**Actor**  
Coach

**Priority**  
Medium

**Acceptance Criteria**

- Coach can view a grid of available materials.
- Coach can select one or multiple materials.
- “No equipment” can be selected as a standalone option.
- Exercise list updates after applying material filters.
- Selected materials are visually highlighted.

## CMS – FR-XXX Filter Exercises by Muscles (List View)

**Description**  
Allow Coaches to filter exercises by targeted muscles using a list-based selector.

**Actor**  
Coach

**Priority**  
Medium

**Acceptance Criteria**

- Coach can view a searchable list of muscles.
- Coach can select one or multiple muscles.
- Selected muscles filter the exercise list.
- Coach can clear muscle selections.
- Filters persist while navigating within the Library.

## CMS – FR-XXX Filter Exercises by Muscles (Human Body View)

**Description**  
Allow Coaches to filter exercises by selecting muscles directly on a human body diagram.

**Actor**  
Coach

**Priority**  
Medium

**Acceptance Criteria**

- Coach can switch from list view to human body view.
- Coach can tap or click a muscle zone on the diagram.
- Selected muscle zones are visually highlighted.
- Exercise list updates according to selected muscles.
- Coach can reset body-based muscle selections.
